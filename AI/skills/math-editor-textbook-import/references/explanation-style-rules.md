# 説明スタイル

説明スタイルで変更できるのは説明量と表現だけであり、問題条件と教科書正答を変えない。教師用解説は解答色本文へ混在させず、問題全体は`ProblemBlock.solution`、個別小問は`SubQuestion.solution`へ格納する。可視内容がない解説は`null`にする。

## `normal`（普通に）

- 教科書解説の意味、説明順序、正答を維持する。
- LaTeX化、段落化、不要な改行除去など形式変換だけを行う。
- 教科書に解説がない場合、新しい解説を追加しない。

## `detailed`（ていねいに）

- 教科書の問題、解答、解説だけを根拠に途中過程を補足する。
- 必要に応じて、考え方、方法を選ぶ理由、計算途中、式変形の理由、注意点、結論を追加する。
- 教科書由来部分とAI補足をDraft内部で識別できるよう変換モードを保持する。
- 根拠が足りない説明や新しい解法を、教科書の説明として断定しない。

## `concise`（端的に）

- 教科書解説を根拠に説明量を減らす。
- 数学的成立に必要な条件、主要式変形、理由、最終結論は残す。
- 短縮で問題条件、例外条件、単位、正答を落とさない。

## 共通確認

変換後に次を照合する。

1. 問題条件が原文と一致する。
2. 最終正答が教科書解答と一致する。
3. 例題の論理順序と使用した前提が保たれる。
4. AI検算との不一致がある場合、教科書解答を保持してWarningを表示する。
5. 教科書解説がない`normal`で解説を新規作成していない。
