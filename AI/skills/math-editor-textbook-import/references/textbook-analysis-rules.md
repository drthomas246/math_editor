# 教科書PDF解析規則

## 受付とPDF種別

1. ファイル存在、PDF拡張子/MIME、読取り可否、ページ数を確認する。
2. 暗号化、破損、権限不足で読めなければFatalとして停止する。
3. ページごとに埋込テキスト取得可否を調べ、`text`、`scan`、`mixed`、`unknown`を決める。
4. 回転情報を適用したページ画像で紙面、数式、問題境界、図版を確認する。

| 種別 | 処理 |
|---|---|
| `text` | 埋込テキストを候補にし、ページ画像で式・配置・境界を照合 |
| `scan` | ページ画像の視覚解析を中心にし、OCRは補助として使用 |
| `mixed` | ページ単位で方式を切り替え、同一問題内で照合 |
| `unknown` | 継続可否を判断し、読めなければFatal |

埋込テキストを無条件に正としない。上付き、下付き、分数、ルビ、段組み、縦書き注記、PDF抽出由来の改行はページ画像と照合する。認識用レンダリングと最終Crop用レンダリングを分ける。

## ページ識別

- `pdfPageNumber`はファイル先頭を1とする物理ページ番号。
- `printedPageLabel`は紙面に印刷された`148`や`p.148`等の任意文字列。
- 最終範囲判定は`pdfPageNumber`で行い、利用者表示には両方を出す。
- 見開きスキャンでもPDF物理ページ単位を維持する。

`p.148`の意味が物理ページか紙面表記か曖昧なら候補を示し、確認前に決めない。

## 範囲候補列

対象ページ上で次を掲載順に候補化し、ページ番号とページ内順序を含む`itemKey`を付ける。

- 例、例題、Example
- 問、問題、練習、演習
- 丸数字、括弧数字、章内で一貫したラベル
- 見出し、罫線、余白で明確に区切られた問題単位

範囲解決：

1. 指定ページを物理ページへ解決する。
2. 指定ラベルを正規化比較する。
3. 同一ラベルが複数なら本文冒頭と出典位置を示して確認する。
4. 開始候補から終了候補までを掲載順で包含する。
5. 開始が終了より後なら`AI_RANGE_ORDER_INVALID` Fatal。
6. 範囲外候補をDraft itemsと最終JSONへ入れない。

漢数字と算用数字を同一視できるが、誤対応の可能性があれば自動確定しない。

## 例題・問題・小問

- 紙面上の解法を示す例、例題、Exampleは`kind: "example"`。
- 練習、問、問題、演習は`kind: "problem"`。
- 解説が付いているだけで例題と判断しない。紙面上の役割が不明ならWarning。

共通指示の下に複数の独立小問がある場合だけ小問構造を使う。段落番号との区別が不明、前小問への文章的依存が強い、複雑な配置の構造化で意味や図版対応が失われる場合は、通常RichTextで掲載順を保持し`AI_PROBLEM_STRUCTURE_UNCERTAIN`を付ける。

2列化して意味と可読性を保てる短い式・選択肢だけ`columns: 2`とする。長文、独立数式、図版、表を含む小問は`columns: 1`。個別に長い小問は`width: "full"`とする。

## 教科書解答・解説の探索

範囲外ページの参照は、対象候補に対応する教科書解答・解説の探索だけに限る。探索順：

1. 同一ページ
2. 対象範囲内の直後ページ
3. PDF内の「解答」「答」「解説」等の明示セクション
4. 問題ラベル、単元、参照ページが一致する候補

一意なら`found`、複数候補なら`ambiguous`、見つからなければ`not-found`。対応候補が複数なら利用者に選ばせる。範囲外から読んだ本文やページ画像は最終JSONに含めない。

教科書解答の優先順位：PDFに明示された解答、PDFに明示された例題の最終結論、利用者が明示訂正した解答。AI検算は整合性警告のためだけに使う。不一致でも教科書内容を保持し、AIの計算結果で上書きしない。未発見時はAI解答を生成・格納しない。
