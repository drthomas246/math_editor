## このアプリでできること

「数学プリント作成」は、中学校数学の問題プリントをパソコンで作るためのアプリです。問題文、数式、画像、表、生徒が書き込む解答欄、先生向けの解説を入力し、完成したプリントをPDFファイルとして保存できます。

作業は主に次の3画面で行います。

| 画面 | できること |
| --- | --- |
| プリント一覧 | 新しいプリントの作成、過去のプリントを開く、検索、複製、バックアップを行います。 |
| 編集画面 | 左側で問題を作り、右側で印刷後の見た目を確認します。 |
| ゴミ箱 | 削除したプリントを元に戻すか、完全に削除します。 |

画面内の「使い方」または丸い「？」ボタンを押すと、このマニュアルが別のタブで開きます。マニュアル上部の検索欄には、「数式」「保存」など、調べたい言葉を入力できます。

## 利用できるパソコンとブラウザ

次の環境で利用してください。

- 最新版のGoogle ChromeまたはMicrosoft Edge
- 画面の横幅が1024px以上あるパソコン
- ブラウザ内へのデータ保存が許可されている環境

「ブラウザ」とは、Webページを見るためのソフトです。スマートフォンや画面の狭い端末では、編集画面とマニュアル本文を表示できません。

## データはどこに保存されるか

作ったプリントは、現在使っているブラウザの中に保存されます。インターネット上のクラウドには保存されません。

そのため、次の場合は同じプリントが自動では表示されません。

- 別のパソコンを使ったとき
- ChromeからEdgeへ変えたとき
- 同じブラウザでも別の利用者プロフィールを使ったとき
- シークレットウィンドウやプライベートブラウズへ切り替えたとき

アカウントへのログイン、クラウド同期、複数人での同時編集には対応していません。

> **重要**
>
> ブラウザの閲覧データを削除したり、パソコンが故障したりすると、プリントを失うことがあります。「設定・バックアップ」から定期的にJSONバックアップを保存してください。JSONは、プリントと画像をまとめて保管するためのファイルです。

初めて使う場合は、[最初のプリントを作る](/help/getting-started)へ進んでください。AIで教科書PDFを取り込む場合は[AI Skillsの使い方](/help/ai-skills)、バックアップについては[バックアップとゴミ箱](/help/backup-and-trash)、版と利用条件については[バージョンとライセンス](/help/version-and-license)で説明します。
