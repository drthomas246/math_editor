## 編集画面の見方

編集画面は、中央の仕切り線で左右に分かれています。

- 左側：問題や解答を入力する「編集」欄
- 右側：PDFにしたときの見た目を示す「プレビュー」
- 上部：一覧へ戻る、題名、保存状態、元に戻す、プリント設定、PDF出力

中央の仕切り線を左右へ動かすと、編集欄とプレビューの幅を変えられます。キーボードを使う場合は、仕切り線を選んで左右の矢印キーを押します。

## 題名を変える

画面上部の題名欄を押して入力します。題名は最大100文字です。空欄のまま別の場所を押すと、「無題のプリント」に戻ります。題名はプリントの先頭にも表示されます。

## 問題と例題を追加する

画面左側の一番下にある「問題・例題を追加」を押すと、選択中の問題の次に新しい項目が入ります。項目左上の選択欄で「問題」と「例題」を切り替えられます。

問題と例題の番号は別々に数えます。たとえば、問題、例題、問題の順に並べると、「問1.」「例1.」「問2.」と表示されます。

問題カード上部では次の操作ができます。

- 「複製」：同じ問題をすぐ下へコピーします。
- 「…」→「上へ移動」「下へ移動」：問題の順番を変えます。
- 「…」→「番号を付ける」：問題番号の表示と非表示を切り替えます。
- 「…」→「この項目から振り直す」：その問題から番号を指定し直します。
- 「…」→「問題を削除」：問題を削除します。

プリントには少なくとも1問が必要なため、最後の1問は削除できません。1つのプリントに追加できる問題と例題の合計は200件です。

> **注意**
>
> 点が並んだつまみをドラッグして並べ替える操作と、メニューに表示されるAlt＋矢印キーは、現在は利用できません。「上へ移動」「下へ移動」を押してください。

## 「内容を追加」を使う

問題カード下部の「内容を追加」を押し、追加したいものを選びます。選択中の内容がある場合は、そのすぐ後ろに追加されます。

| 内容 | 使い方 |
| --- | --- |
| 本文 | 通常の問題文や説明を入力します。 |
| 囲み枠 | 題名付きの枠や強調枠を作ります。デザインを4種類から選べます。 |
| めあて | 解答付きの資料だけに表示する、赤色の説明を入力します。 |
| 小問 | 「(1)」「(2)」のような小問をまとめて作ります。最初は2問です。 |
| 解答欄 | 生徒が書き込む横罫線または四角い欄を作ります。高さは1～20行です。 |
| スペーサー | 1～20行分の空白を入れます。 |
| 改ページ | この位置で次の用紙へ送ります。 |

追加済みの内容を一度押すと、右上に「↑」「↓」と削除ボタンが表示されます。これらを使って順番を変えたり削除したりします。1つの問題には最大100個の内容を追加できます。

数式、画像、表は「内容を追加」にはありません。本文などの文章欄にあるツールバーから挿入します。

## 文章の見た目を整える

本文、囲み枠、めあて、小問、解答欄、教師用の解説には、書式ツールバーがあります。

- 文字サイズ：「小」「標準」「大」「特大」
- 太字、下線、斜体
- 箇条書き、番号付きリスト
- 数式、画像、表の挿入

まず変更したい文字をマウスで選び、その後に太字などのボタンを押します。文章の左揃え、中央揃え、右揃えを変えるボタンは現在ありません。

## 小問を編集する

各小問には、問題文と生徒用解答欄があります。「半幅」では1行に2問、「全幅」では1行に1問の幅で表示します。

「小問を追加」で最大100問まで増やせます。各小問の「…」では、その小問から番号を振り直せます。小問番号の「(1)」「1.」「①」「ア」は、画面上部の「プリント設定」でプリント全体に設定します。

小問の複製と並べ替えには対応していません。削除はできますが、小問グループには少なくとも1問が必要です。

## 教師用の解説を入力する

問題カード下部の「教師用の解説」を押すと、問題ごとの説明欄が開きます。この欄は「解答付き」と「問題＋解答」の解答編にだけ表示されます。

問題色と解答色、生徒用解答欄との違いは[問題色・解答色と教師用の解説](/help/answers)を参照してください。
