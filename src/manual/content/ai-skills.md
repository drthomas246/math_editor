## AIのSkillとは

Skill（スキル）は、決まった作業の進め方をAIに教える「専用の手順書」です。普通のチャットよりも、必要な確認やファイル作成を同じ順序で進めやすくなります。

Math Editorの教科書取込Skillは、教科書PDFの指定範囲を読み取り、問題、数式、図、教科書に掲載された解答・解説を、Math Editorで編集できるJSONファイルに変換します。

SkillはMath Editor画面の中で動く機能ではありません。Skillに対応したAIサービスやAIエージェントでJSONファイルを作り、そのファイルをMath Editorへインポートします。AIからMath Editorへ直接書き込むことはありません。

> **重要**
>
> Skillを使うと、添付した教科書PDFと処理に必要な内容が、利用しているAIサービスの処理環境へ送信されます。Math Editorだけを使う場合の「このブラウザ内への保存」とは異なります。PDFを送信してよいか、授業・校務などで利用する権限があるか、学校や勤務先のルールに反していないかを、始める前に確認してください。

## 始める前に用意するもの

- Math Editorの教科書取込Skillを利用でき、PDFの添付とファイルの保存に対応したAIサービスまたはAIエージェント
- 自分が利用する権限を持っている教科書PDF
- 取り込みを始めるページと問題番号
- 取り込みを終えるページと問題番号
- 例題を含む場合は、解説の詳しさ（「ていねいに」「普通に」「端的に」）

パスワードで保護されたPDFは読み取れません。必要なページと問題番号は、PDFを開いて先にメモしておくとスムーズです。

Math EditorへAIサービスのAPIキーを入力する必要はありません。利用できる機能、回数、ファイルサイズ、料金などは、使用しているAIサービスの契約と設定に従います。

## Skillを使える状態にする

1. 使用するAIサービスまたはAIエージェントを開きます。
2. Skills、拡張機能、Pluginなどの一覧を開きます。画面上の名前はサービスによって異なります。
3. Math Editorの教科書取込Skillを選びます。名前で探す場合は `math-editor-textbook-import` を目印にします。
4. 新しいチャットやタスクを始め、教科書取込Skillを使うことを伝えます。

Skillの選び方には、一覧から押す方法、メッセージ内でSkill名を選ぶ方法、名前を入力して呼び出す方法などがあります。詳しい操作は、使用するAIサービスのヘルプを確認してください。

選択場所が分からない場合は、次の文を送ってAIに確認できます。

```text
利用できるSkillsの一覧を見せてください。
math-editor-textbook-import が利用できるか確認してください。
```

> **注意**
>
> Skill名をメッセージに書くだけでは、未導入のSkillが自動で追加されるわけではありません。一覧にない場合は、そのAIサービスがSkillsに対応しているか、Math Editorの教科書取込Skillが導入・許可されているかを、サービスの管理者または提供元へ確認してください。

## サービス別の始め方の例

画面名や操作方法はAIサービスによって異なります。ここでは、ChatGPTとClaudeで教科書取込Skillを使い始める例を説明します。どちらの場合も、Skillが導入済みであることを確認してからPDFを添付してください。

### ChatGPTの場合

1. ChatGPTを開き、新しいチャットを始めます。
2. メッセージ入力欄に半角の `@` を入力します。
3. 表示されたSkillsの一覧から `math-editor-textbook-import` を選びます。
4. 入力欄にSkill名が表示されたことを確認します。
5. 教科書PDFを添付し、下の「PDFと取り込み範囲を伝える」へ進みます。

ChatGPTでは、依頼内容に合うSkillが自動で選ばれる場合もあります。初めて使うときは、`@`から明示的に選ぶと、使用するSkillを確認しやすくなります。

Skillが一覧にない場合は、ChatGPTのSkillsまたはPluginに教科書取込Skillが導入されているか確認します。学校や勤務先のアカウントでは、管理者によって利用が制限されている場合があります。詳しい仕組みは[ChatGPTの公式Skills説明](https://learn.chatgpt.com/docs/build-skills)を参照してください。

### Claudeの場合

1. Claudeを開き、「Customize」から「Skills」を開きます。
2. `math-editor-textbook-import` が一覧にある場合は、スイッチをオンにします。
3. 一覧にない場合は、教科書取込Skillの配布元から受け取ったZIPファイルを用意します。
4. 「+」、「+ Create skill」、「Upload a skill」の順に選び、ZIPファイルをアップロードします。
5. 新しいチャットを始め、教科書PDFを添付します。
6. 次のように、使用するSkill名を依頼文へ入れます。

```text
math-editor-textbook-import Skillを使って、
添付した教科書PDFをMath Editor用に取り込んでください。
```

Claudeでは、有効になっているSkillの説明と依頼内容が一致すると、自動でSkillが使われます。Skillを確実に指定したい場合は、上の例のように名前を依頼文へ入れます。

「Skills」が表示されない場合は、Claudeの設定でコード実行とファイル作成が有効か確認します。学校や勤務先のアカウントでは、管理者による有効化が必要な場合があります。詳しい手順は[Claudeの公式Skills説明](https://support.claude.com/en/articles/12512180-use-skills-in-claude)を参照してください。

## PDFと取り込み範囲を伝える

1. クリップのボタンなどから教科書PDFを添付します。
2. 開始位置と終了位置を、ページ番号と問題番号の両方で伝えます。
3. 例題を含む場合は、解説の詳しさを伝えます。
4. PDFを送信してよいことと、利用する権限があることを確認する質問に答えます。

初めての場合は、次の文をコピーし、角かっこの中だけを書き換えて使えます。

```text
添付した教科書PDFの、[42]ページの[例題1]から
[45]ページの[問8]までをMath Editor用に取り込んでください。
例題の解説は[普通に]してください。
結果を確認してからJSONを作りたいです。
```

ページ番号は、PDFを表示するソフトのページ数ではなく、紙面に印刷されているページ番号を伝えてください。表紙などのために番号がずれている場合は、「PDFの表示では44ページ、紙面では42ページ」のように両方を伝えます。

## AIの読み取り結果を確認する

AIは、最終JSONを作る前に確認用の結果を表示します。次を問題ごとに確認してください。

- 必要な問題だけが含まれているか
- 問題番号と小問の順番が正しいか
- 分数、根号、指数、添字、符号、括弧が正しいか
- 図やグラフの必要な部分が切れていないか
- 解答と解説が、教科書に掲載された内容と一致しているか
- 「ていねいに」「普通に」「端的に」が希望どおりか

AIは読み間違えることがあります。特に、マイナス記号、指数、小さい文字、図の目盛りは、元のPDFと見比べてください。

直したいときは、普段の言葉で具体的に伝えます。

- `問3は取り込まないでください`
- `問5の x の指数は2です`
- `図の上側を少し広く切り出してください`
- `例題2の解説を「ていねいに」へ変更してください`

修正版が表示されたら、同じ項目をもう一度確認します。教科書内に解答が見つからない場合、SkillはAIが考えた答えを自動で完成データには入れません。必要な解答ページを追加で伝えるか、解答なしの状態を確認してください。

## 内容を確定してJSONを保存する

すべて確認できたら、次のように、JSONを作ることが明確に分かる言葉で伝えます。

```text
この内容で確定し、Math Editor用JSONを作成してください。
```

「よさそう」「進めて」だけでは、確認を求められることがあります。これは、確認前の内容を誤って完成ファイルにしないためです。

Skillが検証を終えると、Math Editor用のJSONファイルが表示されます。ファイルをダウンロードし、見つけやすい場所へ保存してください。JSONの中身を文章ソフトなどで書き換えないでください。

## Math Editorへ取り込む

1. Math Editorのプリント一覧を開きます。
2. 一覧上部の「インポート」を押します。
3. 「JSONファイルを選択」を押し、SkillからダウンロードしたJSONファイルを選びます。
4. 表示されたファイル名とプリント件数を確認します。
5. 「インポート実行」を押します。
6. 追加されたプリントを開き、問題、数式、図、解答、解説を確認します。
7. プレビューで全ページを確認し、必要な部分を編集してからPDFを作ります。

インポートしても、すでにあるプリントは上書きされません。取り込んだプリントは新しいプリントとして追加されます。詳しい操作は[バックアップとゴミ箱](/help/backup-and-trash)を参照してください。

> **注意**
>
> AIの結果は必ず利用者が最終確認してください。Math Editorへ取り込めたことは、問題や解答が数学的に正しいことを保証するものではありません。完成後は通常のJSONバックアップも作ってください。

## Skillでできないこと

初期版の教科書取込Skillは、次の操作には対応していません。

- 新しい問題や類題を自動で作る
- 教科書にない解答や解説を自動で完成データにする
- AIサービスからMath Editorへ直接書き込む
- 教科書PDF全体をMath Editorへ保存する
- 教科書の図やグラフをAI画像として描き直す

JSONを読み込めない場合は、ファイルを手作業で直さず、使用したAIサービスで表示されたエラーをSkillへ伝えて作り直します。それでも解決しない場合は[トラブル対応・制約・ショートカット](/help/troubleshooting)を確認してください。
