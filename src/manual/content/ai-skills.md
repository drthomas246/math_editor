## AIのSkillとは

Skill（スキル）は、決まった作業の進め方をAIに教える「専用の手順書」です。すうがく仕立ての教科書取込Skillは、教科書PDFの指定範囲を読み取り、問題、数式、図、教科書に掲載された解答・解説を、すうがく仕立てで編集できる単一プリントへ変換します。

このSkillは、`sujita-ai`というportable Pluginに収録されています。PDFの読取りとプリントデータの作成は、すうがく仕立て画面ではなく、Pluginを導入したChatGPTまたはCodexの実行環境で行います。完成したプリントは、次のどちらかで取り込めます。

- WebMCPのSite toolsに対応した環境から、利用者の許可後に新しいプリントとして直接追加する
- 検証済みのJSONファイルを受け取り、すうがく仕立ての「インポート」から手動で追加する

> **現在の提供範囲**
>
> v2.1の`sujita-ai` Pluginは、開発者本人が個人用のローカルMarketplaceへ登録して自己テストする段階です。公開Plugin Directoryには掲載しておらず、一般利用者向けのインストール配布は行っていません。すでに`sujita-textbook-import` Skillを利用できる環境では、従来どおりJSONファイルを作る方法を利用できます。

> **重要**
>
> Skillを使うと、添付した教科書PDFと処理に必要な内容が、ChatGPTまたはCodexの処理環境へ送信されます。すうがく仕立てだけを使う場合の「このブラウザ内への保存」とは異なります。PDFを送信してよいか、授業・校務などで利用する権限があるか、学校や勤務先のルールに反していないかを、始める前に確認してください。すうがく仕立てへ送るのは、内容を確定して検証した完成データだけです。PDF本体はすうがく仕立てへ保存しません。

## 始める前に用意するもの

- `sujita-ai` Pluginまたは`sujita-textbook-import` Skillを利用でき、PDF添付とファイル保存に対応したChatGPTまたはCodexの環境
- 自分が利用する権限を持っている、パスワードで保護されていない教科書PDF
- 取り込みを始める紙面ページと問題・例題番号
- 取り込みを終える紙面ページと問題・例題番号
- 必要に応じてプリント題名と、例題の解説の詳しさ（「ていねいに」「普通に」「端的に」）

すうがく仕立てへOpenAI APIキーを入力する必要はありません。処理には利用者自身のChatGPT利用枠を使います。Codexで実行する場合も、サインイン方法と契約に応じた利用枠が適用されます。利用できるモデル、回数、ファイルサイズなどは、利用中の環境と契約に従います。

## Pluginを使える状態にする

### 開発者がローカルで自己テストする場合

この手順は、`sujita-ai`の開発者がv2.1を確認するためのものです。一般公開Pluginのインストール手順ではありません。

1. リポジトリで`npm run plugin:build`を実行し、`dist/sujita-ai/`を生成します。
2. `npm run plugin:verify`を実行し、PluginとSkill正本、Schema、Validatorが一致することを確認します。
3. Codexの`plugin-creator`を使い、検証済みPluginを個人用のローカルMarketplaceへ登録します。
4. ChatGPTデスクトップアプリまたはCodexのPlugin画面を開き、「Personal」から`sujita-ai`をインストールします。Codex CLIでは`/plugins`から同じMarketplaceを選べます。
5. インストール後に新しいチャットまたはタスクを始めます。古い会話には導入したSkillが表示されない場合があります。
6. `@`から`sujita-ai`または`sujita-textbook-import`を選ぶか、依頼文でSkill名を指定します。

更新版を確認するときは、Pluginの検証済みコピーを更新してから再インストールし、新しい会話で試します。削除するときはPlugin画面で`sujita-ai`を開き、「Uninstall plugin」を選びます。Codex CLIでも`/plugins`からアンインストールできます。Pluginを削除しても、すうがく仕立てに保存済みのプリントは削除されません。

Pluginの作成・ローカルMarketplace登録は[OpenAIのPlugin作成ガイド](https://learn.chatgpt.com/docs/build-plugins)、画面からの導入・削除は[OpenAIのPlugin利用ガイド](https://learn.chatgpt.com/docs/plugins)を確認してください。

### Skillが見つからない場合

Skill名をメッセージに書くだけでは、未導入のPluginやSkillは自動で追加されません。Plugin画面に`sujita-ai`がない場合、v2.1では一般公開版を検索して追加することはできません。開発者の自己テスト環境ではローカルMarketplaceへの登録とインストールを確認してください。

## PDFと取り込み範囲を伝える

1. 新しいチャットまたはタスクで、`sujita-textbook-import`を使うよう依頼します。
2. クリップのボタンなどから教科書PDFを添付します。
3. 開始位置と終了位置を、紙面ページと問題・例題番号の両方で伝えます。
4. 例題を含む場合は、解説の詳しさを伝えます。
5. PDFがすうがく仕立ての外部で処理されることと、利用する権限があることを確認する質問に答えます。この確認が済むまでSkillはPDF解析を始めません。

初めての場合は、次の文をコピーし、角かっこの中だけを書き換えて使えます。

```text
sujita-textbook-import Skillを使って、添付した教科書PDFの、
[42]ページの[例題1]から[45]ページの[問8]までを
すうがく仕立て用に取り込んでください。
例題の解説は[普通に]してください。
結果を確認してから完成データを作りたいです。
```

ページ番号は、PDFを表示するソフトのページ数ではなく、紙面に印刷されているページ番号を伝えてください。表紙などのために番号がずれている場合は、「PDFの表示では44ページ、紙面では42ページ」のように両方を伝えます。

## 実行環境の検査を待つ

Skillは、図版処理の前と最終データの組立て・検証の前にRuntime Capability Probeを実行します。これは、現在の実行環境でNode.js、Python、PDF描画、Builder、Validatorなどを実際に利用できるか確認する処理です。利用者がコマンドを手動実行する必要はなく、不足するソフトをSkillが自動インストールすることもありません。

図版処理の結果は、次のように案内されます。

- 主経路を利用可能: 通常の方法で元PDFから図版を切り出します。
- 主経路を利用不可、代替経路を利用可能: 元PDFを使う別の描画方法へ自動で切り替えます。切り出した図は通常どおり確認してください。
- `blocked`: 必須の図版を安全に切り出せない、またはBuilder・Validatorを実行できないため停止します。図を省いた不完全な完成データは作りません。

代替経路でも、教科書の図をAI画像として描き直しません。実行環境を切り替えた場合は、Skillがもう一度検査します。

## AIの読み取り結果を確認する

AIは、最終データを作る前に確認用の結果を表示します。次を問題ごとに確認してください。

- 必要な問題だけが含まれているか
- 問題番号と小問の順番が正しいか
- 分数、根号、指数、添字、符号、括弧が正しいか
- 図やグラフの必要な部分が切れていないか
- 解答と解説が、教科書に掲載された内容と一致しているか
- 「ていねいに」「普通に」「端的に」が希望どおりか
- Warningや未解決の項目が残っていないか

AIは読み間違えることがあります。特に、マイナス記号、指数、小さい文字、図の目盛りは、元のPDFと見比べてください。

直したいときは、普段の言葉で具体的に伝えます。

- `問3は取り込まないでください`
- `問5の x の指数は2です`
- `図の上側を少し広く切り出してください`
- `例題2の解説を「ていねいに」へ変更してください`

修正版が表示されたら、同じ項目をもう一度確認します。教科書内に解答が見つからない場合、SkillはAIが考えた答えを自動で完成データには入れません。必要な解答ページを追加で伝えるか、解答なしの状態を確認してください。

## 内容を確定して配送する

すべて確認できたら、次のように、完成データを作ることが明確に分かる言葉で伝えます。

```text
この内容で確定し、すうがく仕立て用JSONを作成してください。
```

「よさそう」「進めて」だけでは確定になりません。修正すると確定は解除されるため、修正版を確認してからもう一度明示します。

Skillは、確定した内容をBuilderで単一プリントJSONへ変換し、Validatorで形式と画像を検証します。検証に成功した同じ完成JSONを、WebMCPによる直接取込または手動インポートへ配送します。JSONの中身を文章ソフトなどで書き換えないでください。

## WebMCPで直接取り込む

WebMCPのSite toolsは、対応するChatGPTデスクトップアプリの内蔵ブラウザで、開いているすうがく仕立てページとAIが同じ画面・セッションを使うための機能です。Site toolsに対応していない通常のブラウザでは、「AI連携」ボタンは表示されません。

1. ChatGPTの内蔵ブラウザで、取り込み先にするすうがく仕立てのプリント一覧を開いたままにします。本番の正式URLは`https://app.sujita.jp/`です。
2. 開発・自己テストでは、開発サーバーが実際に表示したlocalhost URLをSkillへ伝えます。ポート番号を決め打ちしないでください。
3. 同じすうがく仕立てを複数タブで開いている場合は、AIから候補を示されたときに対象タブを選びます。
4. Skillが対象ページの機能とSchemaを確認し、完成JSONを事前検証するのを待ちます。この時点ではまだ保存されません。
5. 「AI連携を許可してください」と案内されたら、対象ページの「AI連携: OFF」を押します。
6. ダイアログの説明を確認し、このページセッションで新規プリントを追加してよければ「許可」を押します。
7. AIへ許可操作が終わったことを伝えます。Skill自身がこの許可操作を代行することはありません。
8. 取込成功の案内と「AI連携から追加しました」という通知を確認し、一覧に追加された題名を開きます。
9. 問題、数式、図、解答、解説を再確認し、必要な部分を編集してからプレビューとPDFを確認します。

AI連携の許可は、そのページを開いている間だけ有効です。ページを再読み込みするとOFFへ戻ります。直接取込は新しいプリントの追加だけを行い、既存プリントの上書き、更新、削除は行いません。同じ取込要求の通常再試行では、同じプリントを二重追加しないよう処理します。

### 保存先のブラウザプロファイル

直接取り込んだプリントは、すうがく仕立てを開いているブラウザプロファイルのIndexedDBへ保存されます。ChatGPTの内蔵ブラウザと、普段使っているChromeやEdgeが別プロファイルの場合、プリントは自動で共有されません。別のブラウザプロファイルへ移すときは、保存元ですうがく仕立てのJSONをエクスポートし、移動先でインポートしてください。

## 直接取込を利用できないとき

次の場合、Skillは検証済みの完成JSONを変更せず、手動インポートへ切り替えます。

- Site toolsまたは直接取込用のツールが見つからない
- Skillとすうがく仕立てのSchemaが一致しない
- 完成JSONがWebMCP直接取込の2 MiB上限を超えている
- 候補の再検証や通信の安全な再試行を行っても、直接取込を完了できない
- 利用者がAI連携を許可しない、または直接取込を選ばない

Schemaが一致しない場合は、Pluginとすうがく仕立ての版を確認してください。直接取込のためにJSONを手作業で直したり、問題文や図を削ったりしないでください。2 MiBを超えた場合も、同じJSONをそのまま手動で取り込みます。

ページ再読み込みなどで`REVALIDATION_REQUIRED`と案内された場合、Skillは保存してある同じJSONを同じページで最大1回だけ自動再検証し、同じ取込要求として再試行します。再検証を繰り返しても完了しない場合は、手動インポートへ切り替わります。利用者が別の取込要求を作り直す必要はありません。

## JSONファイルを手動で取り込む

1. Skillから検証済みのJSONファイルを受け取り、端末へ保存します。
2. すうがく仕立てのプリント一覧を開きます。
3. 一覧上部の「インポート」を押します。
4. 「JSONファイルを選択」を押し、保存したJSONファイルを選びます。
5. 表示されたファイル名とプリント件数を確認します。
6. 「インポート実行」を押します。
7. 追加されたプリントを開き、問題、数式、図、解答、解説を確認します。
8. プレビューで全ページを確認し、必要な部分を編集してからPDFを作ります。

インポートしても、すでにあるプリントは上書きされません。取り込んだプリントは新しいプリントとして追加されます。別ブラウザへの移動を含む詳しい操作は[バックアップとゴミ箱](/help/backup-and-trash)を参照してください。

> **注意**
>
> AIの結果は必ず利用者が最終確認してください。BuilderとValidatorの検証や、すうがく仕立てへの取込成功は、問題や解答が数学的に正しいことを保証するものではありません。完成後は通常のJSONバックアップも作ってください。

## Skillでできないこと

教科書取込Skillは、次の操作には対応していません。

- 新しい問題や類題を自動で作る
- 教科書にない解答や解説を自動で完成データにする
- AI連携の許可を利用者の代わりにONにする
- 既存プリントをAIから更新・上書き・削除する
- 教科書PDF全体をすうがく仕立てへ保存する
- 教科書の図やグラフをAI画像として描き直す
- Site toolsがない環境へスクリプトを注入して直接取込を代用する

JSONを読み込めない場合は、ファイルを手作業で直さず、表示されたエラーをSkillへ伝えて作り直します。それでも解決しない場合は[トラブル対応・制約・ショートカット](/help/troubleshooting)を確認してください。
