## アプリを開けない

最新版のGoogle ChromeまたはMicrosoft Edgeを使用してください。プライベートブラウズや組織の設定によりブラウザ内保存が制限されている場合は、通常のプロファイルまたは管理者が許可した環境で試します。

## 保存または読込みができない

- ブラウザの空き容量を確認します。
- 同じプリントを複数タブで同時編集していないか確認します。
- 破損したプリントの警告がある場合、元データは自動削除されません。
- タブを閉じる前に保存状態が「保存済み」か確認します。

## PDFやページ配置に問題がある

- PDF生成中はタブを閉じず、プレビューのページ分割完了を待ちます。
- ページ下部が切れる場合は、画像幅、表の行数、スペーサー、余白を小さくするか、明示的な改ページを追加します。
- 印刷時はPDFと同じ用紙サイズ、倍率100%を指定します。

## 主な制約

- 問題のドラッグ＆ドロップ並べ替えには対応していません。問題設定メニューの上下移動を使用します。
- 小問の複製・並べ替え・小問別正解編集には対応していません。
- 1ページより高い1つの内容は、内部で分割または自動縮小されません。
- PDF内の文字は検索・選択できません。
- アカウント、クラウド同期、共同編集はありません。

## キーボード操作

| 操作 | Windows |
| --- | --- |
| 元に戻す | Ctrl+Z |
| やり直す | Ctrl+Y |
| マニュアル検索の解除 | Escape |

解決しない場合は、ブラウザ名と版、画面に表示されたメッセージ、発生した操作、対象ファイルの種類と容量を控えてください。バックアップJSONにはプリント内容が含まれるため、第三者へ共有するときは内容を確認してください。
