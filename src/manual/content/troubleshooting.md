## アプリを開けない

「このブラウザは対応していません」と表示された場合は、最新版のGoogle ChromeまたはMicrosoft Edgeで開き直してください。

会社や学校のパソコンでは、管理者の設定によってブラウザ内への保存が禁止されている場合があります。その場合は、利用できる通常のブラウザプロフィールを使うか、管理者へ確認してください。

編集画面が出ず「PCサイズの画面で利用してください」と表示された場合は、横幅1024px以上の画面で開きます。ブラウザのウィンドウを最大化しても改善しない場合は、より広い画面を利用してください。

## 作ったプリントが見つからない

プリントは、保存したパソコン、ブラウザ、ブラウザプロフィールの中にあります。次を確認してください。

- 前回と同じパソコンを使っているか
- 前回と同じChromeまたはEdgeを使っているか
- 前回と同じ利用者プロフィールを使っているか
- シークレットウィンドウやプライベートブラウズではないか
- 題名検索が残っていないか。「クリア」を押して確認します。
- ゴミ箱へ移していないか

別の環境にあるプリントは自動では同期されません。元の環境でJSONバックアップを作り、新しい環境でインポートします。

## 保存できない

1. 編集画面の「再試行」を押します。
2. パソコンとブラウザの空き容量を確認します。
3. 同じプリントを別のタブで開いている場合は、内容を確認して片方だけを残します。
4. 「保存済み」になるまでタブを閉じません。

問題が続く場合は、まず開けるプリントのJSONバックアップを保存してください。

## 画像を選べない

画像が次の条件を満たすか確認します。

- ファイル形式：PNG、JPEG、WebP
- ファイルサイズ：1点10MiB以下
- 画像の縦と横：それぞれ10,000px以下
- 総画素数：4,000万画素以下

条件を超える場合は、画像編集ソフトなどで画像を小さくしてから選び直します。

## JSONを読み込めない

- ファイルが100MiB以下か確認します。
- このアプリから書き出した、バージョン1のJSONを選びます。
- JSONファイルを文章ソフトなどで書き換えていないか確認します。
- 外部でJSONを加工した場合は、画像のMIME型、実体、寸法が`assets`の記録と一致しているか確認します。
- インポート後の合計が、ゴミ箱を含めて2,000件を超えないか確認します。

インポートは途中の一部だけを読み込む操作ではありません。エラーが出た場合は、プリント一覧に件数が増えていないことを確認してから、元のバックアップを選び直してください。

## 「1ページに収まらない内容があります」と表示される

- プレビューの「更新中…」が消えるまで待ちます。
- 画像の幅、表の行数や行高、解答欄の高さ、スペーサーを小さくします。
- 1つの長い内容を、複数の本文や表に分けます。
- 「改ページ」を追加し、大きな内容を次のページから始めます。
- 「プリント設定」で余白を小さくします。
- 印刷時はPDFと同じ用紙サイズ、倍率「実際のサイズ」または100%を選びます。

1つの内容は途中で分割されず、1ページより高くても自動縮小されません。内容が欠けたPDFを作らないため、警告が出ている間はPDFを保存できません。PDF内の文字は画像になっているため、検索やコピーはできません。

## 主な上限と現在利用できない操作

| 項目 | 上限または現在の状態 |
| --- | --- |
| プリント数 | ゴミ箱を含めて2,000件 |
| 1プリントの問題・例題 | 合計200件 |
| 1問題の内容 | 100個 |
| 1つの小問グループ | 100問 |
| 表 | 20行×20列 |
| 解答欄・スペーサー | 20行 |
| 元に戻す履歴 | 100操作、編集画面を開いている間だけ |
| 問題の並べ替え | メニューの「上へ移動」「下へ移動」を使用。ドラッグ操作は未対応 |
| 小問 | 複製と並べ替え、小問別の教師用解説は未対応 |
| 文章の配置 | 左・中央・右揃えを変えるツールバーは未対応 |
| クラウド機能 | アカウント、同期、共同編集は未対応 |

## キーボード操作

| 操作 | Windows |
| --- | --- |
| 元に戻す | Ctrl+Z |
| やり直す | Ctrl+Y または Ctrl+Shift+Z |
| ダイアログを閉じる | Escape |
| マニュアル検索を解除する | Escape |
| 編集欄とプレビューの幅を変える | 仕切り線を選択して←または→。Shiftを押しながらで大きく移動 |

解決しない場合は、ブラウザ名とバージョン、画面に表示されたメッセージ、直前に行った操作、対象ファイルの種類と大きさを控えてください。バックアップJSONを第三者へ渡す場合は、プリント内容や個人情報が含まれていないか確認してください。
