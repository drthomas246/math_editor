## 用紙や氏名欄を設定する

編集画面上部の「プリント設定」を押します。設定を変えた後は、右下の「適用」を押してください。「キャンセル」を押すと変更しません。

設定できる項目は次のとおりです。

| 項目 | 選べる内容 |
| --- | --- |
| 用紙サイズ | JIS B5（182×257mm）、A4（210×297mm） |
| 用紙の向き | 縦で固定 |
| 余白 | 広い20mm、標準15mm、狭い10mm、かなり狭い5mm |
| 日本語フォント | 5種類から選択 |
| 小問の番号形式 | (1)、1.、①、ア |
| ヘッダーの項目 | 年、組、番、名前 |

余白を小さくすると、用紙に入る内容が増えます。ただし5mmでは、プリンターによって紙の端が欠けることがあります。その場合は10mm以上へ戻してください。

題名と年・組・番・名前は、各出力部分の先頭ページだけに表示されます。「問題＋解答」では、問題編と解答編の先頭にそれぞれ表示されます。

> **注意**
>
> 日本語フォントの選択内容は保存されますが、現在のプレビューとPDFは固定のフォント構成を使います。そのため、選んだフォントへ見た目が変わらない場合があります。

## プレビューの表示を切り替える

プレビュー上部の選択欄で、「問題のみ」「解答付き」「問題＋解答」を切り替えます。表示内容の違いは[問題色・解答色と教師用の解説](/help/answers)を参照してください。

見やすい大きさにするには、次のボタンを使います。

- 「－」「＋」：25～200%の範囲を5%ずつ変更します。
- 「幅に合わせる」：プレビュー欄の横幅に用紙を合わせます。
- 「ページ全体」：用紙全体が見える大きさにします。

プレビューのモード、倍率、左右の欄の幅は同じブラウザ内に記憶され、別のプリントを開いても引き継がれます。

## ページが分かれる仕組み

本文、囲み枠、小問、解答欄、表などの「内容」単位で、用紙に収まるかを判断します。残りの場所へ入らない内容は、次のページへ送られます。

「内容を追加」から「改ページ」を入れると、その位置から新しいページを始められます。章の区切りや、大きな問題の前で使うと配置を揃えやすくなります。

1つの内容が1ページより高い場合、その内容の途中では分割されず、自動縮小もされません。下側が切れるときは、画像の幅、表の行数や行高、解答欄の高さ、スペーサーを小さくするか、内容を複数に分けてください。

## PDFを保存する

1. プレビューで出力したいモードを選び、すべてのページを確認します。
2. 編集画面上部の「PDF出力」を押します。未保存の変更がある場合は、先に保存されます。
3. 「問題のみ」「解答付き」「問題＋解答」から出力モードを選びます。
4. 表示された用紙とページ数を確認します。
5. 「PDFをダウンロード」を押します。

PDFの作成中は「PDF生成中…」と表示されます。完了するまでタブを閉じないでください。

## PDFを印刷する

ダウンロードしたPDFをChrome、Edge、またはPDF閲覧ソフトで開きます。印刷画面では、次を確認してください。

- 用紙サイズ：PDFと同じJIS B5またはA4
- 倍率：「実際のサイズ」または100%
- 向き：縦

PDFの各ページは高解像度の画像として保存されます。このため、PDF内の文字を検索したり、マウスで選んでコピーしたりすることはできません。
